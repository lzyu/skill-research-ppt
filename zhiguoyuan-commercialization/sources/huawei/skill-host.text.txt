托管Skill到AI资产广场
AI资产广场上每个资产的文件都会存储在线上的AI资产广场存储库（简称AI资产广场仓库）里面。每一个Skill实例视作一个资产仓库，Skill与资产仓库之间是一一对应的关系。例如，Skill名称为“Test”，则AI资产广场仓库有个名为“Test”的仓库，其中只存放Test Skill实例的全部文件。
功能说明
支持本地文件托管至AI资产广场仓库且支持多个文件同时上传。
单个仓库的容量上限为50GB。
支持管理托管的资产文件，例如在线预览、下载、删除文件。
只支持预览大小不超过10MB、格式为文本类或图片类的文件。
支持编辑资产介绍。每个资产介绍可分为基础设置和使用描述。
基础设置部分包含了该资产所有重要的结构化元数据信息。选择填入的信息将会变成该Skill资产的标签，并且自动同步在Skill描述部分，保存到“README.md”文件里。
Skill描述部分是一个可在线编辑、预览的Markdown文件，里面包含该Skill的简介、能力描述等信息。编辑内容会自动保存在“README.md”文件里。
更新后的“README.md”文件自动存放在Skill详情页的“文件版本”页签或者是Skill详情页的“Skill文件”页签。
创建Skill资产
登录AI资产广场，单击右上角“我的工作台”进入我的工作台页面。
单击右上方“创建资产”，选择“Skills”后进行参数配置。
表1
创建Skill
参数名称
说明
英文名称
必填项，Skill的英文名称。
如果没有填写
“中文名称”
，则资产发布后，在Skill页签上会显示该
“英文名称”
。
中文名称
Skill的中文名称。
如果填写了
“中文名称”
，则资产发布后，在Skill页签上会显示该
“中文名称”
。
许可证
Skill资产遵循的使用协议，根据业务需求选择合适的许可证类型。
描述
填写资产简介，Skill发布后将作为副标题显示在Skill页签上，方便用户快速了解资产。
支持0~90个字符，请勿在描述中输入涉政、迷信、违禁等相关敏感词，否则发布审核无法通过。
创建完成后，跳转至Skill详情页。
上传Skill文件
在Skill详情页，选择“Skill文件”页签。
单击“添加文件”，进入上传文件页面，选择本地的数据文件单击“点击上传”或拖动文件，单击“确认上传”启动上传。
文件合集大小不超过50GB。
文件上传完成前，请不要刷新或关闭上传页面，防止意外终止上传任务，导致数据缺失。
Skill资产文件上传规范
SKILL.md
SKILL.md 文件必须包含前置元数据（ YAML） ，其后是 正文内容(Markdown ）
字段
是否必填
限制条件
name
是
最多 64 个字符。只能使用小写字母、数字和连字符（-），且不能以连字符开头或结尾。
description
是
最多 1024 个字符。内容不能为空。描述该skill的功能，以及适用于哪些使用场景。
license
否
许可证名称，或指向随附许可证文件的引用。
compatibility
否
最多 500 个字符。说明环境要求，例如适用的产品、系统软件包、网络访问权限等。
metadata
否
用于存储额外元数据的自定义键值映射（由字符串类型的键和字符串类型的值组成）。
allowed-tools
否
以空格分隔的字符串，用于指定该skill获准使用的工具列表。（实验性功能）
Script（可选）
包含Agent可以运行的可执行代码。脚本应：自包含或清楚地记录依赖项，包含有用的错误信息，
优雅地处理边缘情况，支持的语言取决于代理实现。常见选项包括 Python、Bash 和 JavaScript。
References（可选）
包含Agent在需要时可以阅读的附加文档：REFERENCE.md - 详细技术参考，FORMS.md - 表单模板或结构化数据格式，特定领域的文件（finance.md、legal.md 等）。请保持单个参考文件的职责转移性。Agent会在需要时加载这些文件。
当文件状态变成“上传成功”表示数据文件成功上传至AI资产广场仓库进行托管。单击“完成”返回Skill文件页面
