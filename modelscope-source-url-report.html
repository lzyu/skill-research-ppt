口径与缺口

分类规则：本报告只看 source_url 的域名：GitHub → GitHub；已知 Skill 市场域名 → 其他 Skill 市场；其余合法 URL → 外部网站；空值/非 URL 文本 → 无/无效。官方账号本身不单列，因为这里研究的是“内容标源”，不是“谁点的发布”。

已知缺口：公开列表有深分页限制；本次按 10 个一级类目分片，覆盖 81,973/83,552 条（98.1%），仍有 1,579 条未分类未纳入。四类占比只能代表已分类部分。

不要过度解读：GitHub 标源不等于原创，也不等于官方自己上架；Anthropic 等品牌内容本身也可能由魔搭侧镜像导入。外部网站包含企业官网、个人站点、API 文档等，不全是“官方网站”。

与之前抽样差异：2,400 条默认排序样本是 GitHub 73.9%、空 14.2%、BeATra 7.5%；全量分类后是 GitHub 97.5%、空/无效 1.8%、其他市场 0.3%。差异说明默认排序样本严重偏头部；全站长尾大量是 GitHub 导入，不能用 2,400 条样本代表全站。Top10 中仍有 115 万下载/592 浏览的异常值，下载不宜当用户数。
