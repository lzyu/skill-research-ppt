产品介绍

AI 按量付费是支付宝 Agent 支付推出的基于 402 Payment Required HTTP 状态码的 A2M 方案，可让您的 API、数字内容或算力资源，能够直接向访问它们的 AI 智能体（AI Agents）发起自动收款。

我是收款方

接入支付宝 AI 按量付费，让 Agent 调用你的服务时按调用付费，实现服务变现。

我是 Skill 和 MCP 平台商户

一次接入，赋能平台下所有开发者在 Agent 调用服务时进行变现。

核心能力

真正的按用量收费

告别低效率的月费订阅，为每一次 API / MCP-Tool 调用精准定价并收费。

AI 客户自动买单

当 AI 访问你的资源时，A402 自动触发支付请求并完成结算，无需人工干预。

402 协议原生适配

基于 HTTP 402 Payment Required 状态码的 A2M 方案，专为 Agent 调用场景设计。

自动结算

按调用计量、计费和结算，让资源提供方专注服务本身，坐等收钱。

欢迎了解 A402

A402 是一种面向 AI 服务的按量付费方式。

当用户或 AI 应用想调用一个付费能力，比如查询数据、使用工具、生成内容、调用接口时，不需要先注册复杂账号、充值套餐或人工结算。服务方可以直接标明价格，调用方用一次、付一次，付款成功后立即获得服务结果。

简单说，A402 让 AI 服务像扫码买东西一样自然：
需要服务，发起请求；确认价格，完成支付；支付成功，马上使用。

A402 是怎么工作的

发起服务请求

用户或智能体发起服务请求。

返回价格

服务方返回价格。

完成付款

用户或智能体通过支付宝 AI 付完成付款。

校验付款

服务方校验付款是否成功。

返回结果

校验通过后，服务方返回结果。
